## **Способ 1: Ручное добавление**

1. **Перейдите в раздел товаров:**

   -  **Админка -> Магазин -> Товары -> Добавить товар**

2. **Заполните данные вручную:**

   -  Название, цена, описание, категория

   -  Загрузите изображения по одному

---

## **Способ 2: Автоматический импорт через ZIP-архив**

*(Оптимально для большого количества товаров)*

### **Этап 1: Подготовка CSV-файла**

1. **Создайте файл с точным названием:** `goods.csv`

2. **Структура столбцов (строгий порядок!):**

   ```
   Название, Цена, Цена со скидкой, Короткое описание, Описание, Категория
   ```

3. **Добавление характеристик (необязательно):**

   -  Добавляйте дополнительные столбцы **после "Категории"**

   -  Название столбца = название характеристики

4. **Сохранение:**

   -  Формат: **CSV**

   -  Кодировка: **UTF-8**

### **Этап 2: Подготовка изображений**

1. **Создайте папку** `images` (название обязательно на английском)

2. **Варианты добавления изображений:**

   -  **Одно изображение на товар:**

      -  Назовите файл по номеру строки: `1.jpg`, `2.png` и т.д.

   -  **Несколько изображений на товар:**

      -  Создайте папку с номером товара в сsv-файле: `images/15/`

      -  Поместите все изображения товара в эту папку

      -  Названия файлов внутри папки не важны

3. **Оптимизация изображений:**

   -  Сожмите до **100-200 КБ**

   -  Рекомендуемое разрешение: **до 800px по ширине**

### **Этап 3: Создание архива**

1. **В корневой папке должны быть:**

   -  CSV-файл с данными

   -  Папка `images` с изображениями

2. **Создайте ZIP-архив:**

   -  Выделите оба элемента

   -  Добавьте в архив (например, [`goods.zip`](http://goods.zip))

### **Этап 4: Загрузка в бота**

1. **Отправьте команду в чат с вашим ботом:**

   ```
   /add_good
   ```

2. **В ответ на команду загрузите ZIP-архив**

3. **Дождитесь уведомления о завершении импорта**

---

## **Результат:**

-  Все товары появятся в магазине

-  Цены, описания и категории будут заполнены

-  Характеристики отобразятся в карточках товаров

-  Изображения будут прикреплены к соответствующим товарам

---

## **Важные примечания:**

-   **CSV-файл должен называться** `goods.csv`

-  **Папка с изображениями должна называться** `images`

-  **Используйте команду** `/add_good` **перед загрузкой архива**

-  **Сжимайте изображения для быстрой загрузки приложения**

**Готово!** Ваш магазин заполнен товарами. 🛍️
