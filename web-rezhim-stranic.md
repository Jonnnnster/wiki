:::info 

Цель этого режима , перелив трафика через веб прокладку в приложение

:::

🔘 Укажите количество блоков которое будет отображаться

🔘Настройте цвет кнопки и эффект блюра для контента

🔘 Настройте Growth Триггеры - это по сути появляющиеся сообщения типа :

:::quote 

сейчас просматривают X человек

:::

:::quote 

В канал подписалось +100500 тыс. человек 

:::

Текст можете настроить свой

P.S.: так как это веб режим он не поддерживает авторизацию TG аккаунта, а это значит все блоки в которых отображаются товары / страницы / формы - здесь не будут работать -
