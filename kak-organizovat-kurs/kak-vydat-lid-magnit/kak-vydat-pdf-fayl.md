#### **1\. Подготовка PDF-файла**

1. **Загрузите файл** на облачное хранилище:

   -  [Google Drive](https://drive.google.com/)

   -  [Dropbox](https://dropbox.com/)

   -  [Яндекс.Диск](https://disk.yandex.ru/)

   -  Другие сервисы (главное -- получить **прямую ссылку**).

2. **Получите прямую ссылку**:

   -  Ссылка должна заканчиваться на `.pdf`, например:

      ```
      https://example.com/files/guide.pdf
      ```

#### **2\. Размещение ссылки в Notibot**

-  Создайте кнопку в любом блоке (визитка, страница, сообщение бота).

-  В поле **"Ссылка"** вставьте ваш PDF-адрес.

#### **3\. Пример из Notibot**

-  Бот: `@online_cakepro_bot`

-  Ссылка:

   ```
   https://t.me/online_cakepro_bot/aboutme?startapp=a_29FyY2h82hZZbTcMAAZkK2_lp
   ```

   Здесь PDF привязан к кнопке через страницу Notibot.

**Важно!**

🔹 Файл должен быть **доступен без логина** (проверьте настройки хранилища).

🔹 Для больших PDF (от 20 МБ) используйте сжатие ([Smallpdf](https://smallpdf.com/)).

**Готово!** Пользователи смогут скачивать PDF по вашей ссылке. 📄
